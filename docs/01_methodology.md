# Задача 1. Методология выявления ценозависимых клиентов

## 1.0. Данные и обозначения

| Обозначение | Смысл |
|---|---|
| `V[i,t]` | литры клиента *i* в месяце *t* (сен 2023 – май 2024, 9 месяцев) |
| `G[i,t]` | **ценовой разрыв** = цена основной АЗС клиента − средняя цена конкурентов в окружении, ₽/л. `G > 0` — мы дороже |
| `Y[i,t]` | индекс объёма = `V[i,t] / mean_t V[i,·]` (среднее клиента = 1) |
| `A[i,t]` | рыночно-очищенный индекс = `Y[i,t] − mean_{j∈g(i)} Y[j,t] + 1`, где *g* — группа «регион × топливо» |

Выборка: 33 146 клиентов, 642 основные АЗС, 11 регионов. Медианный разрыв +0,8 ₽/л: сеть, как правило, дороже соседей.

Зачем очистка `A`: объёмы зимой и весной падают у всех (сезонность + общий тренд). Вычитая средний индекс «соседей по рынку» в том же месяце, мы оставляем только то, что отличает клиента от рынка, — в том числе реакцию на разрыв **своей** АЗС.

Код: `src/pricesens/features.py`.

## 1.1. Связь разрыва и объёма (агрегатно)

Модель с двусторонними фиксированными эффектами (TWFE):

```
Y[i,t] = a_i + d_{g(i),t} + β · G[i,t] + e[i,t]
```

`a_i` — уровень клиента, `d_{g,t}` — месяц × регион × топливо. Стандартные ошибки кластеризованы по АЗС (цена меняется на уровне станции).

**Результат:** β = −10,9% объёма на +1 ₽ разрыва (SE 0,6 п.п.) → **≈ −5,4% на 50 копеек**.

Месячные изменения (`results/figures/01_gap_vs_volume.png`): рост разрыва > 1 ₽ → −12,8% объёма, снижение > 1 ₽ → +17%.

Разрезы (лист «Эффект по разрезам»): сильнее всего реагируют АИ-92 (−15,7%), форматы Super-M / Super-L, автоматы и киоски; слабее — ДТ (−7,5%).

Код: `src/pricesens/aggregate.py`.

## 1.2. Показатели ценовой чувствительности клиента

Для каждого клиента — МНК по 9 точкам с контролем собственного тренда:

```
A[i,t] = α_i + β_i · G[i,t] + γ_i · t + ε[i,t]
```

| Показатель | Что показывает |
|---|---|
| `β_i` — полуэластичность | доля объёма, теряемая при +1 ₽ разрыва |
| `t_i` — t-статистика `β_i` | насколько реакция выделяется на фоне шума |
| **`p_i` — вероятность ценозависимости** | калиброванная вероятность, что реакция реальна (см. ниже) |
| `resp_up`, `resp_down` | средняя реакция в месяцы, когда разрыв вырос / упал на ≥ 0,5 ₽. Признак «переключателя» — уходит и **возвращается** |
| `β_i^EB` | `β_i`, сжатая к среднему по АЗС × топливо (empirical Bayes) — для оценки величины эффекта без раздувания шумом |
| `γ_i`, доля нулевых месяцев | угасание и нерегулярность, не связанные с ценой |

### Почему нельзя просто взять p-value

Плацебо-тест: каждому клиенту подставляем ценовой ряд случайной АЗС **из другого региона** — такой ряд не может влиять на его заправки. Наивное правило «p < 0,1 и β < −0,2» на плацебо находит ~5,5 тыс. «чувствительных» против ~7,7 тыс. на реальных данных: **≈ 70% находок — ложные**. Причина: 9 точек и гладкие (автокоррелированные) ряды цен и объёмов.

### Калибровка через плацебо (local FDR)

1. Считаем `t_i` на реальных данных — распределение `f(t)`.
2. Десять раз считаем `t_i` на плацебо-ценах — нулевое распределение `f0(t)`.
3. Для каждого бина `t`: `lfdr(t) = f0(t) / f(t)` (сглаживание + монотонность).
4. **`p_i = 1 − lfdr(t_i)`** для `t_i < 0` и `β_i ≤ −0,05`; иначе 0.

Сумма `p_i` — оценка численности когорты: **≈ 2 490 клиентов (7,5%) реально ценозависимы**.

Код: `src/pricesens/metrics.py`, `src/pricesens/calibration.py`.

## 1.3. Алгоритм сегментации

Правила применяются последовательно, следующее перекрывает предыдущее (`src/pricesens/segmentation.py`, пороги — `config.py`):

```
информативен  := размах разрыва ≥ 0,5 ₽  И  активных месяцев ≥ 4

5. Лояльное ядро            — по умолчанию
3. Угасающие (не из-за цены) — γ ≤ −0,06/мес И (последние 3 мес / первые 3 мес) < 0,6
4. Эпизодические            — доля месяцев без заправок ≥ 1/3
2. Вероятно чувствительные  — p ≥ 0,35 И β ≤ −0,10 И информативен
1. «Переключатели»          — p ≥ 0,70 И β ≤ −0,20 И информативен
```

Фильтр информативности отсекает артефакты вида «одна крупная заправка при почти неизменной цене».

## 1.5. Устойчивость и ограничения

| Проверка | Результат |
|---|---|
| Плацебо через весь алгоритм: ложные в сегменте 1 | ~258 из 1 214 (**FDR ≈ 21%**) |
| То же для сегмента 2 | ~927 из 2 029 (FDR ≈ 46%) — поэтому «вероятно» |
| Jackknife (исключение каждого месяца) | 99% сегмента 1 остаются в нём в ≥ 7 из 9 прогонов |
| Две половины периода: эффект < 0 в обеих | 76% у сегмента 1 против 29% по базе |
| Сетка порогов (лист «Пороги») | порог β почти не влияет: 1 153–1 229 клиентов при p ≥ 0,7. Порог вероятности задаёт компромисс точности и охвата: 520 при p ≥ 0,8, ~1 700 при p ≥ 0,6 |
| TWFE без сегментов 1–2 | −7,4% на 1 ₽ (было −10,9%) — вся база **слабо** чувствительна; это вопрос ценовой политики, а не персональных офферов |

**Ограничения подхода**

- 9 месячных точек на клиента: индивидуальные оценки шумные, поэтому решение принимается по калиброванной вероятности, а сегмент 2 используется для теста, а не для вывода.
- Нет транзакций и геоданных: не видно, *куда* ушёл клиент и какие АЗС у него на маршруте; цена конкурентов — среднее по окружению, а не ближайший конкурент.
- Эндогенность разрыва: сеть может сама менять цены там, где падает спрос. Плацебо и очистка от рынка частично это снимают, но причинность лучше подтвердить A/B-тестом оффера.
- «Угасание» может означать переезд, смену машины или работы — без опроса причину не определить.
- Репрезентативность выборки для 13,5 млн участников программы неизвестна.
- Месячная агрегация скрывает реакцию на короткие (несколько дней) ценовые акции соседей.

**Как развивать:** перейти на недельные/транзакционные данные, добавить геотреки из приложения (маршруты, соседние АЗС), заменить правила на иерархическую байесовскую модель (клиент → АЗС → регион) и замкнуть контур: результаты A/B-теста офферов обновляют вероятности.
