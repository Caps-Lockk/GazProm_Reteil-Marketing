# Данные

Положите сюда файл кейса `Кейс_Ретейл_и_маркетинг_Дополнительные_данные.xlsb`
(или его копию в `.xlsx`) под именем `case_data.xlsx` / `case_data.xlsb`.
Данные организатора в репозиторий не коммитятся (см. `.gitignore`).

Ожидаемые листы: `Данные`, `Информация об АЗС`, `Информация о клиентах`,
`Покупки сопутствующих товаров`, `Маржа`, `Плотность`.

Чтение `.xlsb` требует `pyxlsb`. Альтернатива без доп. пакетов:
`soffice --headless --convert-to xlsx case_data.xlsb`.
